# GTA SA x Minecraft Mod — แผนงานและสถานะ

เป้าหมาย: ให้ม็อบ Minecraft (Zombie, Skeleton, Creeper) ต่อสู้/มีปฏิสัมพันธ์กับ NPC
ของ GTA SA ได้จริงในเกม โดย **ใช้ระบบต่อสู้/เลือด/ตำรวจที่เกมมีอยู่แล้ว** แทนที่จะสร้าง
ระบบคู่ขนานขึ้นมาใหม่ทั้งหมด (นี่คือเหตุผลที่ทำให้โปรเจกต์นี้เป็นไปได้ในเวลาที่สมเหตุสมผล)

## แบ่งหน้าที่

**ผม (Claude) ทำ**
- ออกแบบสถาปัตยกรรม เขียนโค้ด C++ ของม็อบ, CI/CD workflow
- ปรับ/แก้โค้ดจาก log และผลทดสอบที่คุณส่งมา

**คุณทำ** (เพราะผมเข้าเกม/มือถือจริงไม่ได้ และเว็บบางหน้าเครื่องมือผมเข้าไม่ถึง)
- มีเกม GTA: SA เวอร์ชันที่รองรับ (ดูด้านล่าง) ที่เป็นเจ้าของถูกต้อง
- ติดตั้ง AndroidModLoader (AML) ตามคู่มือทางการของโปรเจกต์
- ไปหยิบไฟล์โค้ดจริงจาก repo ตัวอย่างมาให้ผม (ดู `docs/research-tasks.md`)
- กด build (ผ่าน GitHub Actions ที่เตรียมไว้ให้) แล้วลงเทสในเครื่อง ส่งผล/ล็อกกลับมา

## ทำไมถึงไม่ต้องเริ่มจากศูนย์

มีเครื่องมือชุมชนที่ทำงานนี้อยู่แล้วและยังมีคนดูแล:

- **AndroidModLoader (AML)** — ตัวโหลดม็อดสำหรับเกม Android (ใช้กับ GTA SA ได้)
  มีระบบ patch/hook ฟังก์ชันในตัวให้แล้ว ไม่ต้องเขียน loader เอง
- **aml-psdk** (github.com/AndroidModLoader/aml-psdk) — SDK สำเร็จรูปสำหรับเขียนม็อด
  เนทีฟของ GTA SA บน Android ตั้งชื่อคลาส/ฟังก์ชันให้ตรงกับ `DK22Pac/plugin-sdk`
  ซึ่งเป็น SDK มาตรฐานที่ reverse เกมฝั่ง PC ไว้ละเอียดมาก (มี CPed, CTask, CPools,
  CEventHandler ฯลฯ พร้อมใช้) → เราได้ "ชื่อฟังก์ชัน" มาใช้แทนที่จะต้องไล่หา address
  เองทุกตัวด้วย Ghidra
- **GTASA_PedFuncs** (github.com/AndroidModLoader/GTASA_PedFuncs) — ตัวอย่างม็อดจริง
  ที่แก้ไขพฤติกรรม ped โดยเฉพาะ และมี **GitHub Actions build ผ่านอยู่แล้ว** —
  พิสูจน์ว่าสาย CI ที่เราจะทำนี้มีคนทำสำเร็จมาก่อน ไม่ใช่ของใหม่ที่เสี่ยง

เกมที่รองรับโดย aml-psdk ตอนนี้: **GTA: SA v2.00** หรือ **v2.10 (64-bit)**

## แผนระยะยาว (milestone)

0. ✅ ตั้งโครงโปรเจกต์ + CI เบื้องต้น (ไฟล์ชุดนี้) — ⏳ รอไฟล์จริงจาก aml-psdk มา confirm
1. Spawn ped ใหม่ด้วยโมเดล zombie (ยังไม่มี AI)
2. ใส่ custom task ให้ม็อบหาเป้าหมายใกล้สุดแล้ววิ่งเข้าหา
3. เรียกฟังก์ชัน damage เดิมของเกมตอนเข้าประชิด (เลือด/ล้ม/ตายใช้ของเดิม)
4. เช็กว่า NPC โต้กลับ + ตำรวจตอบสนองเองไหม (ถ้า hook ถูกจุด ควรได้มาฟรีจากระบบเดิม)
5. เพิ่ม Skeleton (reuse task ยิงปืนของ ped ติดอาวุธ) และ Creeper (reuse ฟังก์ชันระเบิด)

**ความคืบหน้าล่าสุด:** คุณส่ง `lib/arm64-v8a` จริงจากเกมมาให้ (ดีกว่าที่ขอไว้อีก) —
`libGTASA.so` ไม่ได้ strip เลยเปิดดูด้วย `nm`/`readelf` ได้ตรงๆ ได้ที่อยู่ฟังก์ชันจริง
ของเวอร์ชันเกมคุณมาแล้ว **milestone 1 เขียนโค้ดจริงเสร็จแล้ว รอคุณ build + ทดสอบ**
(ดูรายละเอียดที่มาที่ไปของทุกที่อยู่ใน `docs/findings.md`)

## ไฟล์ในชุดนี้

- `mod/src/mod_main.cpp` — โค้ด milestone 1 จริง: รอ 8 วิหลังโหลด แล้ว spawn ped
  ทดสอบข้างๆ ผู้เล่น โดยเรียกฟังก์ชัน `CPopulation::AddPed` ของเกมตรงๆ
- `mod/Android.mk`, `mod/Application.mk` — ไฟล์ build สำหรับ `ndk-build` (arm64-v8a)
- `.github/workflows/build.yml` — CI build `.so` อัตโนมัติทุกครั้งที่ push ไฟล์ผลลัพธ์
  โหลดได้จากแท็บ Actions ของ repo
- `docs/findings.md` — แคตตาล็อกที่อยู่ฟังก์ชัน/enum ที่ยืนยันแล้วจากไบนารีจริงของคุณ
  (ไว้ใช้ต่อใน milestone ถัดๆ ไป)
- `docs/research-tasks.md` — การบ้านเดิม (ยังมีประโยชน์สำหรับ milestone 3+ ที่ต้องใช้
  AML::Hook จริงจัง)

## สิ่งที่ต้องทำต่อ (ขั้นตอนทดสอบ)

1. วาง `mc_zombie_mod.so` (ได้จาก GitHub Actions หรือ build เอง) ลงในโฟลเดอร์ mods
   ของ AML บนเครื่อง (path ที่แน่ชัดเช็กจากคู่มือ/การตั้งค่า AML ของคุณ)
2. **เซฟเกมก่อน** แล้วเข้าเกมในพื้นที่โล่งๆ (ไม่ใช่กลางคัตซีนหรือภารกิจ)
3. รอ ~8 วินาทีหลังเข้าเกม ดูว่ามีตัวละครโผล่ข้างๆ คุณไหม
4. ไม่ว่าจะสำเร็จหรือไม่ ช่วยดึง logcat ที่มี tag `MCZombieMod` ส่งกลับมา
   (เช่น `adb logcat -s MCZombieMod`) จะได้รู้ว่าต้องแก้ตรงไหนต่อ
