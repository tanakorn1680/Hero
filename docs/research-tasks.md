# สิ่งที่ต้องหามาให้ผม

เหตุผล: เครื่องมือเว็บของผมเข้าหน้า "ดูไฟล์โค้ด" ตรงๆ บน GitHub ไม่ได้ (ถูกบล็อก
อัตโนมัติ) เลยต้องขอให้คุณช่วยคัดลอกเนื้อหามาวางในแชทแทน จะได้เขียนโค้ดที่ตรงกับ
API จริง ไม่ใช่โค้ดที่ผมเดาเอง

## ขั้น 1 — ยืนยันเกม + AML ใช้งานได้ก่อน (ทำได้เลยไม่ต้องรอผม)

1. ติดตั้ง GTA: SA เวอร์ชัน **v2.10 (64-bit)** หรือ **v2.00**
2. ติดตั้ง AndroidModLoader (AML) ตามคู่มือทางการของโปรเจกต์ (ค้นหา repo หลักของ
   AndroidModLoader บน GitHub)
3. ลองโหลดม็อดเล็กๆ ที่มีคนทำไว้แล้วมาลงทดสอบ เพื่อยืนยันว่า AML ทำงานในเครื่อง
   คุณได้จริงก่อนที่เราจะเริ่มเขียนม็อดเอง

## ขั้น 2 — ขอไฟล์จริงจาก repo ตัวอย่าง (อันนี้ผมต้องรอ)

เปิด 2 ลิงก์นี้ แล้วคัดลอกเนื้อหาไฟล์ส่งกลับมาในแชท (วางเป็นข้อความหรือแนบไฟล์ก็ได้
ไม่ต้องสรุป เอาโค้ดเต็มๆ):

**จาก https://github.com/AndroidModLoader/aml-psdk**
- `main.cpp`
- `Android.mk`
- `Application.mk`
- ทุกไฟล์ใน `examples/game_sa/`

**จาก https://github.com/AndroidModLoader/GTASA_PedFuncs** (มี CI ใช้งานได้จริง
อยู่แล้ว — อันนี้สำคัญที่สุด)
- `main.cpp`
- `Android.mk`
- `.github/workflows/main.yml` ← เอามาเทียบกับ `build.yml` ที่ผมร่างไว้ให้

## ขั้น 3 — เมื่อผมได้ไฟล์พวกนี้แล้ว

ผมจะเขียนโค้ด milestone 0-1 จริง (spawn ped + confirm build) ให้คุณ build/ทดสอบ
ต่อได้ทันที แทนที่จะเป็นโครงร่างเดาแบบตอนนี้
